Write slides in Typst.
Present them in motion.

Glissade adds animation state, formula morphing, and draw-in effects to Typst slides, then exports a single portable HTML presentation with sharp vector frames.

Timeline as code

Primitives →

Declare values with init, change them with animate, then, and meanwhile, and read them with a("name") anywhere in the slide.

Vector-native motion

Formula morphing →

Morph formulas part by part, interpolate SVG geometry, and draw shapes in. Frames stay resolution-independent at any screen size.

One portable file

Export a self-contained HTML file with compressed SVG frames and the browser runtime. It opens locally, no server needed.

presenting

Playback pauses at every cut. You decide when it continues.

A cut is a boundary you place in the timeline. The animation plays up to it and waits for you, and a looping cut repeats its segment while you talk.

plays cut()waits plays cut()waits repeats ↻ cut(loop: true)until you continue

quick start

Stay in Typst.
Test in the browser.

Requires Python 3.10+ and Typst. Video export also needs FFmpeg.

Read the guide →
  1. Install

    From a checkout of the repository:

    uv tool install .
  2. Preview

    Rebuild on every save and scrub through frames:

    glissade slides.typ dev
  3. Export

    Package everything into one HTML file, like the example deck:

    glissade slides.typ html --fps 24

status

Early version, open design.

Glissade is experimental, so the Typst API and export format may change. It started from Kino as its animation foundation and explores how that proof of concept fits a browser-focused presentation workflow. Feedback and issues are welcome on GitHub.
