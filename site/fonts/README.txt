Fonts in this directory
=======================

newcm-book.woff2         from NewCM10-Book.otf
newcm-book-italic.woff2  from NewCM10-BookItalic.otf

These are modified copies of New Computer Modern 8.1.1 by Antonis Tsolomitis
(C) 2019-2026, released under the GUST Font License:
https://tug.org/fonts/licenses/GUST-FONT-LICENSE.txt

Modifications: each file is a subset limited to Latin text, punctuation and a
few arrows, without hinting, converted to WOFF2 and renamed. Nothing else was
changed. The website loads them under the family name "NewCM Web".

The complete, unmodified fonts are available from CTAN:
https://ctan.org/pkg/newcomputermodern
